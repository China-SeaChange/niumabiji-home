# 牛马笔记

> 灵感跑不掉，牛马不焦虑 —— 在 AI 时代，你只管复制粘贴。

牛马笔记是一个**完全免费、纯本地保存**的单文件笔记工作台。复制网页、AI 回答、聊天记录里的任意内容，`Ctrl+V` 粘贴即成卡片、自动归档，记录、整理、回顾、沉淀全在同一个页面闭环完成。

## 为什么做它

现在的 AI 时代，几乎每个职场牛马都在跟 AI 打交道：问问题、找工作、想方案、写材料。AI 张口就来，总能给出不少启发和灵感——但回答太快、信息太多，根本来不及第一时间归纳整理。上一秒还觉得惊艳的思路，下一秒就淹死在聊天记录里。

所以牛马笔记只做一件事：把「收集」变得毫无门槛。**复制、粘贴，自动变成卡片、自动归档**。先收下，整理的事交给以后。

## 核心特性

| 类别 | 能力 |
| --- | --- |
| 零门槛收集 | 任意位置 `Ctrl+V` 直接粘贴成卡片，网页 / 富文本复制自动转成 Markdown |
| 纯本地保存 | 数据只存在你自己的浏览器里，不上传、不联网、无账号 |
| Markdown 全渲染 | 标题层级、加粗、列表、表格、代码块、链接、任务项完整显示 |
| 无限撤销 / 恢复 | `Ctrl+Z` 撤回、`Ctrl+Y` 恢复，对新增、删除、置顶、调整分类等所有操作都生效 |
| 卡片即插即用 | 双击卡片进入编辑，编辑 / 预览双模式，宽大弹窗可全屏 |
| 智能归档 | 粘贴自动归入当前分类；未粘贴在「全部文档」下则归入「未分类」 |
| 分类体系 | 图标 + 颜色自由配置（预设色板 / 拾色器），支持重命名、置顶、拖拽排序 |
| 拖拽整理 | 长按卡片拖到任意位置互换卡片、拖入分类自动改归类 |
| 星星评价 | 1–5 星标记重点，再点一次可取消 |
| 专注阅读 | 展开卡片底部固定「收起」按钮；右上角图标一键全屏查看 |
| 全局缩放 | 右下角按钮放大 / 缩小卡片预览尺寸（60%–150%），一键恢复默认 |
| 主题切换 | 浅色 / 暗黑一键切换，暗黑背景单一连贯渐变 |
| 交互音效 | 点击、保存、删除、拖拽、置顶等 12 种操作音效 |
| 备份导出 | 一键导出 JSON 备份，标题名自动同步为文件名 |
| 初始模式 | 一键恢复初始模式（浅色主题、默认三分类、100% 缩放），不删除已有卡片 |

## 快速开始

1. **下载** `工作备忘录.html` 这一个文件（单文件自包含，无需安装任何依赖）。
2. **双击打开**，在浏览器里直接使用。
3. 看到好内容 → `Ctrl+C` 复制 → 回到页面任意位置 `Ctrl+V`，卡片即刻生成。

首次打开会有引导说明，勾选「下次不再提示」即可跳过。

## 快捷键

| 快捷键 | 作用 |
| --- | --- |
| `Ctrl / ⌘ + V` | 任意位置粘贴成卡片，自动归入当前分类 |
| `Ctrl / ⌘ + Z` | 撤销（新增 / 删除 / 置顶 / 调整分类等所有操作） |
| `Ctrl / ⌘ + Y` | 恢复 |
| `Ctrl / ⌘ + Enter` | 编辑弹窗内快速保存 |
| `双击卡片` | 进入编辑模式 |
| `长按卡片（约 0.45 秒）` | 抓取拖拽：互换卡片位置 / 拖入左侧分类 |

> 长按拖拽特意设置了 0.45 秒的锁定时间：单击选中、滑选复制文字不受影响，快速滑动不会误触发。

## 数据与隐私

- 所有数据保存在浏览器 `localStorage`（键名 `work-memo-v2-*`），**纯本地、不上传、不联网**。
- 换设备 / 换浏览器不会自动同步——需要迁移时，用「导出 JSON」备份后在新设备「导入」即可。
- 清理浏览器站点数据会清空笔记，重要内容请定期导出备份。

## 分类说明

- 默认预设三个分类：**工作 💼**、**生活 🌱**、**其他 📁**（均可改名、改图标、改颜色）。
- 「未分类」固定显示在分类列表**末尾**，收纳粘贴时不属于任何分类的内容。
- 双击分类名可打开弹窗编辑：128 个图标任选、12 种预设颜色 + 原生拾色器。
- 分类也可以长按拖拽，调整在左侧导航中的排列顺序；置顶的分类有图钉标记。

## 技术说明

- 单文件 HTML（原生 JS + CSS），无框架、无构建、无后端，双击即用。
- Markdown 渲染支持标题层级、表格、代码块等完整语法。
- 富文本 / 网页内容复制后自动转换为 Markdown 再入卡。
- 撤销恢复基于操作快照栈（`pushHistory`），覆盖全部结构性操作。
